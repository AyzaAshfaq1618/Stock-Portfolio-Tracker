# Stock Portfolio Tracker  

A simple Python project built during my internship at **CodeAlpha**.  
This program helps track stock investments with hardcoded prices, user input, and portfolio value calculation.  

---

## Features
- Hardcoded stock prices (`AAPL`, `TSLA`, `MSFT`, `GOOGL`)
- User can enter stock symbols & quantities
- Calculates **total investment value**
- Saves results to:
  - `portfolio.csv`
  - `portfolio.txt`
